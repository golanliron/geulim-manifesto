# מותג גאולי

גאולי היא קהילת ההורים של בית ספר גאולים בשכונת בקעה.

התיקייה הזו שומרת את נכסי הבסיס של המותג כדי שכל עמוד, טופס או הרחבה עתידית יישארו באותה שפה: שם, לוגו, פונטים וצבעים.

## שם המותג

הכתיב הראשי:

```text
גְּאוּלִי
```

שם תיאורי:

```text
גאולי · קהילת ההורים של בית ספר גאולים בשכונת בקעה
```

## לוגו

- `assets/logo/geuli-symbol.svg` - סמל העלים בתוך מסגרת.
- `assets/wordmark/geuli-wordmark.svg` - השם גְּאוּלִי בלבד.
- `assets/logo/geuli-lockup.svg` - סמל + שם + שורת תיאור.

## פונטים

- כותרת מותג/שם: `Noto Serif Hebrew`, גיבוי `Frank Ruhl Libre`.
- כותרות משנה חגיגיות: `Frank Ruhl Libre`.
- טקסט רץ וממשק: `Heebo`.
- פונט אופציונלי קצר/דקורטיבי: `Secular One`.
